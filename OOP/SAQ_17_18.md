## 1. Define object with example

An object is an instance of a class. It represents a real-world entity and contains data (variables) and behavior (methods).

```java
class Student {
    String name;

    Student(String n) {
        name = n;
    }

    void display() {
        System.out.println("Name: " + name);
    }

    public static void main(String[] args) {
        Student s1 = new Student("Rahim");
        s1.display();
    }
}
```

Here, `s1` is an object of the Student class.

## 2. Suppose you have three variables: One for temporary calculation, one for storing object-specific data, and one shared across all objects. Identify which variable should be local, instance, and static.

Java variables can be classified into local, instance, and static variables based on their use.

1. **Local Variable:** A variable declared inside a method or block. It is used for temporary calculations.
2. **Instance Variable:** A variable declared inside a class but outside methods. It stores object-specific data.
3. **Static Variable:** A variable declared using `static`. It is shared by all objects of the class.

### Example:

```java
class Student {
    static int count; // Static variable
    String name; // Instance variable

    void display() {
        int x = 10; // Local variable
    }
}
```

- Temporary calculation → Local variable
- Object-specific data → Instance variable
- Shared by all objects → Static variable

## 4. You need to illustrate a method that should be accessible to subclasses but not accessible to unrelated classes in other packages. Choose the most appropriate access modifier for this method.

### protected Access Modifier

The most appropriate access modifier is `protected`.

- A protected method can be accessed by subclasses, even when they are in a different package.
- It cannot be directly accessed by unrelated classes in other packages.

### Example:

```java
protected void display() {
    System.out.println("Hello");
}
```

Therefore, `protected` is the correct access modifier.

## 5. Evaluate how access modifier control the visibility of class members, and provide one example to support your explanation.

### Access Modifier and Visibility

An access modifier controls the visibility and accessibility of class members such as variables and methods.

Java has four access modifiers:

- `private` → accessible only within the same class.
- `default` → accessible within the same package.
- `protected` → accessible within the same package and subclasses.
- `public` → accessible from anywhere.

### Example

```java
class Student {
    private int age = 20;
    public String name = "Rahim";
}
```

Here, `age` is private, so it can only be accessed inside the Student class. `name` is public, so it can be accessed from anywhere. Thus, access modifiers control the visibility of class members.

## 6. Demonstrate the concept of polymorphism in Java with an example.

Polymorphism means “many forms.” In Java, it allows the same method name to perform different tasks depending on the object or parameters.

```java
class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        Calculator c = new Calculator();
        System.out.println(c.add(10, 20));
        System.out.println(c.add(10, 20, 30));
    }
}
```

## Method Overloading

```java
void display(int a)
void display(double a)
```

### a) Analyze the above methods and state whether they are overloaded or not.

### b) What happens if two methods have the same name and the same parameter list?

**A.** Yes, the methods are overloaded because they have the same method name `display()` but different parameter types (`int` and `double`).

```java
void display(int a)
void display(double a)
```

This is an example of method overloading.

**b)** If two methods have the same name and same parameter list, they are not considered overloaded.

Java does not allow two methods with the same signature in the same class.

It creates a compile-time error.

The compiler cannot distinguish between the two methods.

For method overloading, the parameter list must be different.

The return type alone cannot be used for method overloading.

## 2. A program has three variables: one declared inside a method, one declared inside a class without static, and one declared with static. Identify which is local, which is instance, and which is static. Justify your answer.

1. **Local Variable:** The variable declared inside a method is a local variable because its scope is limited to that method.
2. **Instance Variable:** The variable declared inside a class without `static` is an instance variable because each object has its own copy.
3. **Static Variable:** The variable declared with `static` is a static variable because it is shared by all objects of the class.

### Example:

```java
class Student {
    int age; // Instance variable
    static int count; // Static variable

    void display() {
        int marks = 80; // Local variable
    }
}
```
